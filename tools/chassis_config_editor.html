底盘几何

轮序必须与电机 ID 和 PID 行顺序一致。当前运动学实现固定为四轮。

车轮安装角

角度单位为弧度；修改布局时请确认 FK 与 IK 使用同一组数据。

四轮速度 PID

车轮KpKiKd输出限幅积分限幅积分分离阈值
四个车轮当前共用同一个输出限幅。编辑器会检查四组 PID 的输出限幅一致。

遥控与斜坡

斜坡参数表示每个控制周期允许的目标速度变化量。

自动巡航

车辆按设定距离往返；端点需连续满足停稳条件后才换向。

电机与 CAN 映射

通常在更换电机、调整总线 ID 或修正电机模型时修改。

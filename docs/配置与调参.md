# 底盘与云台配置及调参

本文说明底盘和云台参数的 YAML 配置、离线编辑器与 Ozone 实时调参方法。

## YAML 配置源

底盘和云台参数分别维护在：

- `config/chassis.yaml`
- `config/gimbal.yaml`

不要直接编辑生成的配置头文件：

- 底盘：`User/Module/Chassis/ChassisConfig.hpp`
- 云台：`User/Module/Gimbal/GimbalConfig.hpp`

CMake 会在构建时根据 YAML 自动生成头文件。修改 YAML 后重新构建并烧录，参数才会成为固件默认值。

## 环境依赖

需要 Python 3.8 或更新版本及 PyYAML。在项目根目录运行：

```powershell
python -m pip install -r tools/requirements.txt
```

## 手动生成配置头文件

在项目根目录运行：

```powershell
python tools/generate_chassis_config.py
python tools/generate_gimbal_config.py
```

两个脚本分别生成底盘和云台模块中的配置头文件。正常构建时 CMake 会自动运行生成步骤。

## 离线配置网页

从项目根目录启动编辑器：

```powershell
python tools/chassis_config_editor.py
```

浏览器访问 `http://127.0.0.1:8765`，可进入底盘配置、云台配置或挡位说明页面。底盘和云台页面支持编辑参数、保存到项目 YAML 或导出 YAML。

“默认参考参数”会恢复最近一次从 YAML 载入或成功保存的参数；保存新参数后，参考值也会随之更新。“归零”会把 PID 的 Kp、Ki、Kd 设为零，云台页面还会把重力前馈设为零。挡位说明页面展示 S1、S2 两个三档拨杆的九种组合。网页编辑器不会连接机器人，也不会直接改变运行中的固件。保存配置后需要重新构建并烧录。

## Ozone 实时调参

底盘与云台的运行时调参变量分别位于 `ChassisTuning` 和 `GimbalTuning` 命名空间中。这些变量放在 RAM 中并声明为 `volatile`，可在 Ozone 的 Watch 窗口中查看和修改。例如：

```text
ChassisTuning::WHEEL_PID_KP[0]
ChassisTuning::REMOTE_LINEAR_GAIN
GimbalTuning::HIGHT_PID_KP
GimbalTuning::HIGHT_GRAVITY_FEEDFORWARD
```

修改会在控制代码读取这些变量后的运行周期中生效；断电或复位后会恢复为 YAML 生成的默认值。确认合适数值后，将其写回对应 YAML 并重新构建，作为后续固件的默认值。调试时使用带调试符号的 Debug 固件（`build.ps1` 默认构建 Debug），并在 Ozone 中加载对应的 ELF 文件。

具体可调变量以以下声明和控制代码的实际读取为准：

- `User/Module/Chassis/ChassisTuning.hpp`
- `User/Module/Gimbal/GimbalTuning.hpp`

硬件 ID、车轮数量、机械布局和限位电平等编译期配置，不属于一般运行时调参项。

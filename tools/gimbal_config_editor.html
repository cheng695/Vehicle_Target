云台参数离线配置

在本机编辑 gimbal.yaml。更改在重新编译并烧录后生效；此页面不连接机器人。

配置来源：config/gimbal.yaml · 参数说明显示在每个字段下方

Yaw 速度规划

设置遥控模式下的角速度限幅、滚轮步长和变速曲线。

Hight 行程与速度规划

行程角度按减速器输出端累计角度填写；减速比变化会影响角度换算。

电机 PID 与前馈

轴KpKiKd输出限幅积分限幅积分分离阈值
重力前馈建议值：有装甲板 850，无装甲板 500。当前 YAML 值会在上方显示，可按实际负载调整。

上下限位与堵转检测

上下限位有效电平可以分别配置。当前堵转检测未启用。

升降 GM3508 配置

更改数量或 ID 时，需确认硬件接线和 CAN 映射一致。

Yaw J4310 配置

MIT 参数依次为位置、速度、力矩、Kp 和 Kd 的最小值与最大值。
